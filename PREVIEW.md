# HoneyTide garden-journal revision

This revision restores every original photo and video element, including source paths, order, video playback attributes, and image dimensions. Original media files are not edited. Media container styling is retained except for decorative borders/shadows and the homepage logo display size.

The design introduces leafy botanical margins, warm textured paper, sage navigation, expressive italic headings, beeswax buttons, torn-paper hero edges, taped photo borders, and open editorial sections instead of rounded cards.

## See it

Open https://github.com/MythiCam/HoneyTide-Website/tree/nature-first-preview then Code > Download ZIP. Extract All, open the extracted folder, and double-click index.html. Download again if you have the first preview; that older ZIP will not update automatically.

The draft pull request remains https://github.com/MythiCam/HoneyTide-Website/pull/10 . It has not been merged into the live site.

All six pages were checked against the original site for exact media element attributes and order. Original media bytes are unchanged in the proposed GitHub update. Local links and stylesheet syntax are checked separately. Browser verification status is reported with delivery.
