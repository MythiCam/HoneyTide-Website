# Nature-first preview

This branch is a first implementation for Cam to review. It does not change the live GitHub Pages site until merged into its publishing branch.

## View the design

1. Open this branch on GitHub: https://github.com/MythiCam/HoneyTide-Website/tree/nature-first-preview
2. Choose the green Code button, then Download ZIP.
3. Extract the ZIP (Windows: right-click > Extract All).
4. Open index.html inside the extracted folder in your browser. Keep the images and css folders beside it.
5. Follow the navigation to compare all pages. Resize the browser to inspect narrow layouts.

GitHub Desktop alternative: Fetch origin, choose Current Branch > nature-first-preview, then Repository > Show in Explorer and open index.html. Save or commit unrelated local work before switching branches.

## Changes

Photo-led homepage with shorter first-person copy, shared nature palette, smaller WebP derivatives preserving original artwork/photos, no autoplay background videos, user-controlled colony video, contact email link, corrected image dimensions, clearer keyboard focus, and sitemap maintenance. Other pages retain their main content and receive shared palette improvements.

Product availability stays conservative. The current colony total requires confirmation; the Apiary counter now describes the four featured colony stories rather than asserting a live colony count.
